# 애매한 질문 테스트 세트 (2026-11-06)

목적: 독자·목적·형식 중 둘 이상이 빠진 짧은 요청에서 prompt-refiner가 효과를 내는지 측정한다.
세 arm을 비교한다. R = 원문 질문 그대로(자료가 있으면 자료만 덧붙임). P = 리파이너가 질문하고 사용자가 답한 뒤 만든 프롬프트. C = 원문 질문 + 사용자가 리파이너 질문에 답한 문장을 그대로 덧붙임(정보량을 P와 맞춘 대조군).
의도 카드는 사용자가 실제로 원했던 것이다. 리파이너 arm에는 보이지 않고, 질문에 답할 때와 판정 브리프에만 쓴다. 표본은 가정으로 작성했다.
