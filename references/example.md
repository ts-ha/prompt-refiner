# Example (형식 참고용. 도메인, 분량 숫자, 제약 문구는 따르지 않는다)

입력: "견적서 엑셀 보고 고객용 요약 메일 써주는 프롬프트"

### 1. 의도 요약과 보완 포인트
의도: 견적서를 근거로 고객용 요약 메일을 쓰는 AI 지시문.
보완: 수신자, 입력 자료 위치, 숫자 생성 금지 제약, 검증 조건을 추가.

### 2. 정제된 프롬프트
````markdown
역할: B2B 기술지원 영업 담당자의 관점. 판단 기준은 고객이 한 번 읽고 다음 행동을 알 수 있는가.
목표와 완료 조건: [견적서]를 근거로 고객 담당자에게 보낼 요약 메일 초안 1건.
입력 자료: [견적서 xlsx]의 항목명, 수량, 단가, 합계.
출력 형식: 한국어 비즈니스 메일. 제목 1줄, 짧은 본문, 핵심 항목 표 1개.
제약: 견적서에 없는 숫자 생성 금지. 미확인 항목은 [확인 필요]로 표시.
성공 기준: 합계가 견적서와 일치한다. 다음 행동 제안이 한 문장 들어간다. 항목 해석이 불확실하면 추측하지 않고 표시한다.
````

### 3. 가정
- 수신자는 기술 배경이 있는 구매 담당자.

### 4. 확인 질문
- 할인 가능성을 언급해도 되나요? (제약 슬롯)
